## Featured Project

### AI-Based Network Intrusion Detection and Security Monitoring System

A machine-learning-based network security project focused on identifying potentially malicious network activity and presenting security analysis through a web-based monitoring interface.

The project uses the **UNSW-NB15 dataset** and evaluates multiple classification approaches, including **Logistic Regression, Decision Tree, Random Forest, and XGBoost**. It is implemented with **Python and Scikit-learn**, with a **Django-based web application** supporting CSV-based batch prediction and model-performance visualization.

**Core focus areas:**

- Machine-learning-based intrusion detection
- Network security analysis
- Comparative model evaluation
- CSV-based batch prediction
- Model-performance visualization
- Django application development
